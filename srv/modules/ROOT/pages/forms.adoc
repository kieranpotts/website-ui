= Forms
:page-description: Preview of form controls.

Form controls are styled via the `Form` component. They are rendered in AsciiDoc using literal blocks.

== Buttons

++++
<nav class="Form">
  <button>Reset</button>
  <button>Save</button>
</nav>
++++

== Text inputs

++++
<form class="Form">

== Disclosure component

The `details`/`summary` elements are styled directly, not via the `Forms` component.

++++
<details>
  <summary>A short summary of the contents</summary>
  <p>Hidden gems. This content is revealed when the disclosure is opened.</p>
</details>
<details open>
  <summary>This one starts open</summary>
  <p>Its contents are visible until the reader collapses it.</p>
</details>
++++
