=== Code blocks

[source,python]
----
def fibonacci(n):
    """Generate Fibonacci sequence up to n terms."""
    if n <= 0:
        return []
    elif n == 1:
        return [0]

    sequence = [0, 1]
    for i in range(2, n):
        sequence.append(sequence[i-1] + sequence[i-2])

    return sequence

# Example usage
fib_sequence = fibonacci(10)
print(f"First 10 Fibonacci numbers: {fib_sequence}")
----

== User interface elements

Press kbd:[Ctrl+C] to copy and kbd:[Ctrl+V] to paste.

Click the btn:[Save] button to save your changes.

Navigate to menu:File[Save As] to save with a different name.

Select menu:Edit[Find > Replace] to open the find and replace dialog.
