= The Monospace Web: a Theme Preview
:page-description: A single rich page exercising a broad range of AsciiDoc constructs for theming the Antora UI.

This single page exercises a broad range of AsciiDoc constructs so the theme
can be designed against realistic content. It deliberately mixes prose,
images, code, tables, lists, and block elements.
